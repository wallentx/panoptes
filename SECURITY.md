# Security Policy

## Supported Versions

Panoptes is pre-1.0. Security fixes target the latest code on the `main` branch.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/wallentx/panoptes/security/advisories/new).

Include the Panoptes version, `panoptes version` output, platform, and a minimal
reproduction. Do not include secrets or private source code.
